## What the refuters killed (guardrails — full list in refuted_claims.md)

1. **Stock soft-prompt recipe on Falcon-E = garbage** — AutoBitLinear
   offline-mode weight_scale convention is inverted for this checkpoint;
   outputs measured ~300× wrong (ws² error). Corrected recipe: patch packed
   BitLinear with ActQuant STE (keep divide-convention scales) or invert all
   168 scales; TORCHDYNAMO_DISABLE=1; custom loop; MANDATORY step-0
   logit-parity gate. No prior art anywhere — we'd be first (evidence
   discipline maximal).
2. **Stock onebitllms cannot run on free T4s** — Triton ≥3.3 dropped Turing
   (CC 7.5). Gate: pinned env torch≤2.6 (bundles triton 3.2) + onebitllms
   0.0.4 + pinned TRL.
3. **"2× width restores fp16 parity" for tiny ternary is FALSE as parity** —
   BitNet-Reloaded's own Table 1 contradicts it beyond the smallest cells.
   Treat 2× width as a FLOOR; target = quality of a ≤half-size fp16 twin.
4. **transformers CPU decode is 0.25 tok/s** (re-measured with log; the 0.34
   figure had no log behind it — provenance flaw caught). All generation
   evals route through OUR engine (4.8 tok/s); transformers side is for
   teacher-forced loglikelihood only (6.4 tok/s, 1.12GB RSS — measured).
5. **Claude/frontier-API-generated training data is DEAD** — Anthropic
   consumer terms prohibit training on outputs; DARPA provenance risk.
   Claude works on tooling/filters/harnesses only, never training text.
6. **Local 8B-teacher bulk datagen DEAD** (463 days / 100M tokens);
   **cross-tokenizer logit KD DEAD** (32,768 vs 128,256 vocab mismatch).

## Critic amendments (all adopted)

- **Provenance honesty on synthetic corpora:** TinyStories is GPT-3.5/4
  generated (CDLA-Sharing-1.0); Tulu-3 contains OpenAI-generated subsets;
  SmolTalk's Magpie-Ultra was generated by Llama-3.1-405B — which triggers
  the Llama-3.1 license **naming flow-down** ("Llama" prefix requirement) on
  any model trained on it. Sovereignty framing is therefore **"own training
  run on openly licensed data"**, never "own data". The M2 ledger carries a
  per-subset **generator-model column**, not just license.
- **M2 stays TEXT-FORM** with token counts recorded for BOTH tokenizers
  (Falcon-E 32,768 / Llama-3 128,256); final sizing happens after M5 picks
  the M6 vehicle.
- **M7 gets a real baseline:** train the half-size fp16 twin (~5–7M params,
  1–3 days at measured throughput) — the honest comparison DARPA will ask
  for; without it the M7 gate is unmeasurable.
- **M6 domain eval must exist before M6:** defined and built during M2/M3
  (held-out items, metric, engine-side JSONL format), pre-registered.
- **One-heavy-job serial calendar** (see below) — the box is currently owned
  by the BitNet full-testset PPL re-run (~24–30h from 2026-07-17 20:13).
- **Disk eviction rule:** `df` logged before every multi-day run; masters
  mirrored to external drive then deleted locally before M2 bulk downloads.
  **BINDING as of 2026-07-17 21:20: the rule fired its first casualty** —
  an unscoped smoltalk2 snapshot_download (402 files incl. a 124-shard
  Nemotron reasoning subset) filled the disk to ENOSPC mid-repack; partials
  deleted, 24GB recovered. New law: NEVER snapshot_download without
  allow_patterns; query repo file sizes via the hub API first; keep ≥8GB
  free at all times (a MODEL.SAF write + checkpoint must always fit).
- **New hedge modality (M4d, parked):** activation steering / control
  vectors over frozen ternary (repeng-style, zero training, per-layer bias
  add in-engine). Untested against ternary quantization — that IS the
  experiment, if M4a's parity gate fails.
